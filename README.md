# TSG – Comparativo de plataformas de capacitación

Sitio estático ejecutivo para presentar el comparativo entre Buk, Moodle y Odoo.

## Contenido
- Resumen ejecutivo
- Comparativo funcional
- Comparativo de inversión
- Evaluación gerencial
- Fortalezas y riesgos
- Lectura estratégica para TSG

## Despliegue
Compatible con Vercel como proyecto estático. No requiere build command.
